# Draft App Review notes

Wardrobe Reset is a local-first wardrobe decision and maintenance tool. No login or demo account is required.

Core test path:

1. On Reset, enter an item and choose one of seven decisions.
2. Choose Maybe, add a future date and allow or deny the local notification prompt.
3. Choose Keep or Sell, then use Add Photo to test the native camera/photo prompt. Photographs are optional and remain in app-local storage.
4. Open Maintain to view and share the summary.
5. Open Data & privacy to export or delete all local app data.

The app contains no advertising, analytics, user account, cloud backend, user-generated public content, in-app purchase or subscription. Camera/photo access and notification access are requested contextually and are not required for the core checklist.
